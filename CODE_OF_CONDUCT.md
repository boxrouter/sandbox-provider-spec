# Code of Conduct

This project follows the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/).
Everyone taking part in the project's spaces, such as issues, pull requests and
discussions, is expected to follow it.

## Reporting

Report a possible violation to conduct@boxrouter.ai. Reports are handled in confidence. A maintainer
involved in a report takes no part in handling it.

## Enforcement

The maintainers act as the Covenant's Community Moderators and use its enforcement ladder.
